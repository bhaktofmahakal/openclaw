# OpenClaw Code of Conduct

OpenClaw is built in public by a distributed group of contributors, maintainers, and users.
We want the project to stay technically rigorous, welcoming, and safe for everyone who participates.

## Our expectations

When participating in this project, please:

- Be respectful, direct, and constructive.
- Focus on evidence, reproduction steps, and code when discussing technical disagreements.
- Assume good intent while still holding a high bar for correctness and review quality.
- Welcome contributors with different backgrounds, experience levels, and communication styles.
- Keep feedback scoped to the work, never the person.

## Unacceptable behavior

The following behavior is not acceptable in project spaces, including issues, pull requests, discussions, Discord, and other OpenClaw community channels:

- Harassment, threats, or personal attacks.
- Discrimination or demeaning language based on personal characteristics.
- Repeated bad-faith arguing, trolling, or intentionally derailing technical discussions.
- Publishing private information without permission.
- Spam, impersonation, or other abusive behavior that makes collaboration unsafe.

## Scope

This Code of Conduct applies to:

- GitHub issues, pull requests, reviews, discussions, and commits in this repository.
- OpenClaw-managed communication spaces where contributors are representing the project.

## Reporting

If you experience or witness behavior that violates this Code of Conduct, contact the maintainers at `contributing@openclaw.ai`.

Please include as much context as you can, such as links, screenshots, timestamps, and a short description of what happened.

## Enforcement

Maintainers may take any action they deem necessary to protect the project and its contributors, including:

- Asking for behavior to stop or for a conversation to move back on topic.
- Removing comments or content.
- Temporarily or permanently restricting participation in project spaces.

We will review reports as promptly and fairly as we can.
